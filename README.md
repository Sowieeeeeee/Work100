# Hot 100 本地训练器

把力扣 Hot 100 的简单/中等题拆成每天固定份量，在本地计时、记录状态、按间隔复习。写代码支持两种模式：**ACM 模式**（完整程序，含 main 与输入输出）和**核心代码模式**（力扣官方 `class Solution` / 设计类签名），在写代码界面一键切换。判题用例与力扣官方一致，一个不减。全部用 Python 标准库，不依赖外部服务。

当前数据：88 道题（20 简单 + 68 中等，不含困难题），截止 **2026-11-10**，每天 19:30–23:00，新题 25 分钟、复习 15 分钟。按剩余题量和天数自动调整每天新题数，上限 7 道。

## 现在就能用

桌面上有 **Hot100 训练台** 快捷方式：双击即启动服务并打开仪表盘；服务已经在运行时，只会打开页面，不会重复启动。

快捷方式使用自定义图标 `assets/hot100.ico`。如果移动了项目目录，或者想重建快捷方式，运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools/create_shortcut.ps1
```

默认用**文字模式**，不用启动任何本地服务：

```bash
python trainer.py text
```

它会打印今日计划，并给出第一道未完成题的题面、ACM 输入输出和样例。练习时把代码发到会话里即可，样例校验仍由本机的 `check` 完成。

文字模式下不需要计划任务，也不需要浏览器；之前安装的 `Hot100Trainer` 任务已经删除。想要图形界面时仍可选：

- 仪表盘：`python trainer.py serve`，然后打开 <http://127.0.0.1:8765/>
- 恢复每日自动启动：`python trainer.py install-task`

## 每天怎么练

文字模式：

1. `python trainer.py text` 查看今天要做的题。
2. 只实现 `solve(...)`，把代码发到会话里；输入解析和输出由模板处理。
3. 我把它写入 `solutions/` 并运行官方样例（等价于 `python trainer.py check 1`）。
4. 按真实情况记录状态：独立完成 / 借提示完成 / 看题解后复现 / 未完成。

仪表盘模式（可选）：

1. 打开仪表盘，点当天第一题的“开始计时”。
2. 点“写代码”进入全屏写代码工作台：左侧是整份预生成代码（ACM 模式含 main、输入解析、输出和全部辅助函数；核心代码模式是力扣签名加平台提供的节点类），**任何部分都可以删改**，包括删掉 main 自己重写。
3. 顶部切换 **ACM 模式 / 核心代码模式**，每种模式的代码分开保存（`solutions/` 与 `core/`），切换前自动保存，下次打开记住上次的模式。
4. 编辑时后台自动预编译（状态灯显示“已编译 / 语法错误 · 第 N 行”，点灯跳到出错行），停止输入约 1 秒后自动保存；也可以 `Ctrl+S` 手动保存。
5. 点“运行全部用例”或 `Ctrl+Enter`：隔离子进程跑完该题全部官方用例，右侧给出通过率圆环、通过/未通过/错误数、总/平均/最大耗时，以及逐用例的输入、期望输出、你的输出和错误详情（点用例行展开）。
6. “重置模板”两次确认后恢复预生成代码；“题面”按钮随时看题面。
7. 点“完成本题”，按真实情况选择状态。

四个状态决定后续安排：

| 状态 | 含义 | 后续 |
| --- | --- | --- |
| 独立完成 | 没看提示、没看题解 | 不强制复习 |
| 借提示完成 | 看过提示，自己写出来 | 1 天、5 天后各复习一次 |
| 看题解后复现 | 看过参考题解 | 1 天、4 天后各复习一次 |
| 未完成 | 25 分钟没做出来 | 明天优先重新排入 |

每天最多安排 2 道到期复习；复习到期多于 2 道时自动顺延，仪表盘会提示积压。每天的时间槽从 19:30 开始依次排，新题和复习都会标在时间线上。

状态会按实际使用情况校正：如果这题用过提示，即使点了“独立完成”，也会记为“借提示完成”；看过参考题解则记为“看题解后复现”，确保复习间隔不会漏掉。

## 文件位置

```
problems/     题面（题意、约束、ACM 输入输出、官方全量样例）
solutions/    ACM 模式代码：整份程序可删改
core/         核心代码模式代码：力扣签名脚手架，可删改
reference/    参考题解（带中文注释，建议先独立完成）
data/         题集、配置、SQLite 进度（含每次运行的通过率记录）
logs/         服务日志
assets/       快捷方式图标（hot100.ico / hot100.png）
tools/        数据集构建、官方用例刷新、判题回归、快捷方式脚本
trainer.py    命令行入口
hot100/       计划、计时、判题、仪表盘、提醒
```

模板示例（`solutions/0001-two-sum.py` 的末尾）：

```python

    raise NotImplementedError("删掉这一行，写下你的解法")
```

每个文件的头部会写明这道题的 ACM 输入顺序和输出格式。链表、二叉树、设计题（LRU、Trie、最小栈）也都有对应的纯文本输入适配。核心代码模式的脚手架则直接给力扣官方 Python3 签名，链表/树节点类预先提供、可删掉自己重写。

## 判题与官方用例

- 用例 = 力扣判题接口的 `exampleTestcases` 与题面页示例的**并集**，共 **88 题 / 223 个用例**，不删减；期望输出优先取题面原文，缺失的由参考解 oracle 补齐。
- 两种模式跑同一套用例：ACM 模式比对标准输出；核心代码模式由判题驱动构造参数、调用签名并规范化返回值。链表环/相交、BST 形状等答案不唯一的题按结构判定。
- 判题在隔离子进程里执行，单题总时限 30 秒；超时被杀时已跑完的用例结果仍然保留。
- 预编译对用户无感知：编辑时后台 `compile()` 并缓存字节码，运行时直接把字节码交给判题进程，不需要点任何“编译”按钮。
- 每次运行记录通过率与耗时（`data/state.db` 的 `code_runs`），工作台显示历史最佳。

回归与数据刷新：

```bash
python -m tools.verify_judge            # 88 题 × 223 用例 × 双模式，全过才退出 0
python -m tools.refresh_official_cases  # 用例变化时刷新 problems.json 与题面（不覆盖已有代码）
```

## 常用命令

```bash
python trainer.py text                # 文字模式：今日计划 + 下一题题面
python trainer.py text 49             # 直接看 #49 的题面
python trainer.py status              # 今日计划、进度、警告
python trainer.py start 1             # 开始 #1（计时）
python trainer.py finish 1 done       # 标记独立完成
python trainer.py finish 1 hinted     # 标记借提示完成
python trainer.py check 1             # 用官方样例自测
python trainer.py hint 1              # 提示 1
python trainer.py hint 1 2            # 提示 2
python trainer.py reference 1         # 查看参考题解（会记录）
python trainer.py serve               # 可选：启动仪表盘和提醒
python trainer.py rebuild             # 按新配置重排今天
```

完成状态也接受中文：`独立完成`、`借提示完成`、`看题解后复现`、`未完成`。

## 改计划

仪表盘右上角“设置”可以改：截止日期、练习时段、新题/复习分钟数、每天上限、桌面提醒、自动打开仪表盘。保存后会重排今天还没开始的题；已开始或已完成的题不会动。

命令行等价写法：

```bash
python trainer.py config --deadline 2026-11-20
python trainer.py config --session-start 20:00 --session-end 23:30
python trainer.py config --max-new-per-day 6
python trainer.py rebuild
```

如果剩余题量按每天上限也排不进截止日期，`status` 会给出明确警告，不会假装能完成。

## 提醒机制

以下功能只在运行 `python trainer.py serve` 时生效，文字模式不会打扰你：

- 计划任务每天 19:25 启动服务（登录状态下运行；目前已删除，需要时用 `install-task` 恢复）。
- 19:30 弹出开始提醒；如果配置允许，自动打开仪表盘。
- 某一题的计划时间到了且还没开始计时，会提醒下一题。
- 正在计时的题到 15 分钟且没用过提示，会提醒可以看提示。
- 到本题时间上限会提醒收尾。
- 23:00 后提醒标记未完成的题。
- 同一天同类提醒只发一次，重启服务不会重复弹。

桌面提醒是本地 Tkinter 小窗口，不依赖系统通知权限；关闭窗口不影响训练器。移动项目目录或修改练习开始时间后，重新运行 `python trainer.py install-task`，让计划任务指向新路径/新时间。

## 复习和排题逻辑

- 每天先算剩余题数 ÷ 剩余天数，向上取整，封顶 7 道新题。
- 未完成的题 `retry=1`，第二天排在新题最前面。
- 借提示/看题解后复现的题写入复习队列，按 1/5 天或 1/4 天到期。
- 复习到期但当天名额已满时顺延，不丢弃。
- 已经完成的题不会再次作为新题出现。
- 跨天时，前一天没开始的计划项标记为过期，进度和复习记录保留。
- 跨天仍挂着的计时会在下次打开时自动结束，按上限记为未完成，第二天优先重排；计时器不会继续累加。

## 题库和参考解

- `data/problems.json`：88 道题的元数据、题面、ACM I/O 和官方全量样例。
- `tools/build_dataset.py`：把 `data/raw_questions.json` + `data/plan_raw.json` 重新整理成 `problems.json`。
- 参考解全部按 ACM 模式实现，含中文注释；已用官方全量用例在两种模式下校验：**88 道题、223 个用例、0 失败**。
- 换题集时，除了重新生成 `problems.json`，还需要在 `hot100/bank/` 里为新增题目补参考解和提示；题面/模板会根据数据自动生成。

## 环境

- Windows 10/11，Python 3.10+（当前机器 3.12）。
- 只用标准库；仪表盘只监听 `127.0.0.1`，不向外部上传代码或进度。
- 进度存在 `data/state.db`，删掉这个文件等于清空进度；`python trainer.py reset --yes` 是同样的效果。

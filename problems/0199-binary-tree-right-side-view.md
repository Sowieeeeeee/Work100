# 199. 二叉树的右视图

中等 · 二叉树 · [力扣原题](https://leetcode.cn/problems/binary-tree-right-side-view/)

## 题意

给定一个二叉树的 **根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

## 约束

- 二叉树的节点个数的范围是 `[0,100]`
- `-100 <= Node.val <= 100`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。

## ACM 输出格式

- 一行，空格分隔的整数；空数组输出空行。

## 样例 1

输入：

```text
7
1 2 3 null 5 null 4
```

输出：

```text
1 3 4
```

## 样例 2

输入：

```text
8
1 2 3 4 null null null 5
```

输出：

```text
1 3 4 5
```

## 样例 3

输入：

```text
3
1 null 3
```

输出：

```text
1 3
```

## 样例 4

输入：

```text
0
```

输出：

```text

```

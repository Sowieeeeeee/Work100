# 347. 前 K 个高频元素

中等 · 堆 · [力扣原题](https://leetcode.cn/problems/top-k-frequent-elements/)

## 题意

给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案。

## 约束

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` 的取值范围是 `[1, 数组中不相同的元素的个数]`
- 题目数据保证答案唯一，换句话说，数组中前 `k` 个高频元素的集合是唯一的

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。
- `k`：一个整数。

## ACM 输出格式

- 一行，空格分隔的整数；空数组输出空行。

## 样例 1

输入：

```text
6
1 1 1 2 2 3
2
```

输出：

```text
1 2
```

## 样例 2

输入：

```text
1
1
1
```

输出：

```text
1
```

## 样例 3

输入：

```text
10
1 2 1 2 1 2 3 1 3 2
2
```

输出：

```text
1 2
```

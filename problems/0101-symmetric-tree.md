# 101. 对称二叉树

简单 · 二叉树 · [力扣原题](https://leetcode.cn/problems/symmetric-tree/)

## 题意

给你一个二叉树的根节点 `root` ， 检查它是否轴对称。

## 约束

- 树中节点数目在范围 `[1, 1000]` 内
- `-100 <= Node.val <= 100`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。

## ACM 输出格式

- true 或 false。

## 样例 1

输入：

```text
7
1 2 2 3 4 4 3
```

输出：

```text
true
```

## 样例 2

输入：

```text
7
1 2 2 null 3 null 3
```

输出：

```text
false
```

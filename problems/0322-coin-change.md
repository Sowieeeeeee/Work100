# 322. 零钱兑换

中等 · 动态规划 · [力扣原题](https://leetcode.cn/problems/coin-change/)

## 题意

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。

计算并返回可以凑成总金额所需的 **最少 **的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1 。

你可以认为每种硬币的数量是无限的。

## 约束

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `coins`：先读长度 n，再读 n 个整数。
- `amount`：一个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
3
1 2 5
11
```

输出：

```text
3
```

## 样例 2

输入：

```text
1
2
3
```

输出：

```text
-1
```

## 样例 3

输入：

```text
1
1
0
```

输出：

```text
0
```

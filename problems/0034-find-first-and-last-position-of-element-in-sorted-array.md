# 34. 在排序数组中查找元素的第一个和最后一个位置

中等 · 二分查找 · [力扣原题](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

## 题意

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

## 约束

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是一个非递减数组
- `-10^9 <= target <= 10^9`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。
- `target`：一个整数。

## ACM 输出格式

- 一行，空格分隔的整数；空数组输出空行。

## 样例 1

输入：

```text
6
5 7 7 8 8 10
8
```

输出：

```text
3 4
```

## 样例 2

输入：

```text
6
5 7 7 8 8 10
6
```

输出：

```text
-1 -1
```

## 样例 3

输入：

```text
0

0
```

输出：

```text
-1 -1
```

# 20. 有效的括号

简单 · 栈 · [力扣原题](https://leetcode.cn/problems/valid-parentheses/)

## 题意

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

 - 左括号必须用相同类型的右括号闭合。

 - 左括号必须以正确的顺序闭合。

 - 每个右括号都有一个对应的相同类型的左括号。

## 约束

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `s`：一行字符串。

## ACM 输出格式

- true 或 false。

## 样例 1

输入：

```text
()
```

输出：

```text
true
```

## 样例 2

输入：

```text
()[]{}
```

输出：

```text
true
```

## 样例 3

输入：

```text
(]
```

输出：

```text
false
```

## 样例 4

输入：

```text
([])
```

输出：

```text
true
```

## 样例 5

输入：

```text
([)]
```

输出：

```text
false
```

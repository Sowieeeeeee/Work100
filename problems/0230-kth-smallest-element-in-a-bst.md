# 230. 二叉搜索树中第 K 小的元素

中等 · 二叉树 · [力扣原题](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)

## 题意

给定一个二叉搜索树的根节点 `root` ，和一个整数 `k` ，请你设计一个算法查找其中第 `k`** **小的元素（`k` 从 1 开始计数）。

## 约束

- 树中的节点数为 `n` 。
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。
- `k`：一个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
5
3 1 4 null 2
1
```

输出：

```text
1
```

## 样例 2

输入：

```text
8
5 3 6 2 4 null null 1
3
```

输出：

```text
3
```

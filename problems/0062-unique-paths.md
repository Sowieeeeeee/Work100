# 62. 不同路径

中等 · 多维动态规划 · [力扣原题](https://leetcode.cn/problems/unique-paths/)

## 题意

一个机器人位于一个 `m x n`* *网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

## 约束

- `1 <= m, n <= 100`
- 题目数据保证答案小于等于 `2 * 10^9`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `m`：一个整数。
- `n`：一个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
3
7
```

输出：

```text
28
```

## 样例 2

输入：

```text
3
2
```

```text
3
```

## 样例 3

输入：

```text

3
```

输出：

```text
28
```

## 样例 4

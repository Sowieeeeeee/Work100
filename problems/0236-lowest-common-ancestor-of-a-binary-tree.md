# 236. 二叉树的最近公共祖先

中等 · 二叉树 · [力扣原题](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

## 题意

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”

## 约束

- 树中节点数目在范围 `[2, 10^5]` 内。
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` `互不相同` 。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。
- `p`、`q`：两个整数，表示目标结点的值。

## ACM 输出格式

- 目标节点的值。

## 样例 1

输入：

```text
11
3 5 1 6 2 0 8 null null 7 4
5
1
```

输出：

```text
3
```

## 样例 2

输入：

```text
11
3 5 1 6 2 0 8 null null 7 4
5
4
```

输出：

```text
5
```

## 样例 3

输入：

```text
2
1 2
1
2
```

输出：

```text
1
```

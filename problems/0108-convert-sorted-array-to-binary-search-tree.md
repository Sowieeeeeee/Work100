# 108. 将有序数组转换为二叉搜索树

简单 · 二叉树 · [力扣原题](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

## 题意

给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵 平衡 二叉搜索树。

## 约束

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 按 **严格递增** 顺序排列

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 先输出层序长度，再输出层序 token；null 表示空结点。

## 样例 1

输入：

```text
5
-10 -3 0 5 9
```

输出：

```text
6
0 -3 9 -10 null 5
```

## 样例 2

输入：

```text
2
1 3
```

输出：

```text
2
3 1
```

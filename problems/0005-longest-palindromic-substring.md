# 5. 最长回文子串

中等 · 多维动态规划 · [力扣原题](https://leetcode.cn/problems/longest-palindromic-substring/)

## 题意

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

## 约束

- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `s`：一行字符串。

## ACM 输出格式

- 一行字符串。

## 样例 1

输入：

```text
babad
```

输出：

```text
bab
```

## 样例 2

输入：

```text
cbbd
```

输出：

```text
bb
```

# 45. 跳跃游戏 II

中等 · 贪心算法 · [力扣原题](https://leetcode.cn/problems/jump-game-ii/)

## 题意

给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置在下标 0。

每个元素 `nums[i]` 表示从索引 `i` 向后跳转的最大长度。换句话说，如果你在索引 `i` 处，你可以跳转到任意 `(i + j)` 处：

 - `0 <= j <= nums[i]` 且

 - `i + j < n`

返回到达 `n - 1` 的最小跳跃次数。测试用例保证可以到达 `n - 1`。

## 约束

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- 题目保证可以到达 `n - 1`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
5
2 3 1 1 4
```

输出：

```text
2
```

## 样例 2

输入：

```text
5
2 3 0 1 4
```

输出：

```text
2
```

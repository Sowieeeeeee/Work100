# 114. 二叉树展开为链表

中等 · 二叉树 · [力扣原题](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)

## 题意

给你二叉树的根结点 `root` ，请你将它展开为一个单链表：

 - 展开后的单链表应该同样使用 `TreeNode` ，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null` 。

 - 展开后的单链表应该与二叉树 **先序遍历** 顺序相同。

## 约束

- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。

## ACM 输出格式

- 按层序输出展开后的链表（只使用右指针），null 表示空位。

## 样例 1

输入：

```text
7
1 2 5 3 4 null 6
```

输出：

```text
11
1 null 2 null 3 null 4 null 5 null 6
```

## 样例 2

输入：

```text
0
```

输出：

```text
0
```

## 样例 3

输入：

```text
1
0
```

输出：

```text
1
0
```

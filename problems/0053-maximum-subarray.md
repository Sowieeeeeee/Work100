# 53. 最大子数组和

中等 · 普通数组 · [力扣原题](https://leetcode.cn/problems/maximum-subarray/)

## 题意

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组 **是数组中的一个连续部分。

## 约束

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
9
-2 1 -3 4 -1 2 1 -5 4
```

输出：

```text
6
```

## 样例 2

输入：

```text
1
1
```

输出：

```text
1
```

## 样例 3

输入：

```text
5
5 4 -1 7 8
```

输出：

```text
23
```

# 169. 多数元素

简单 · 技巧 · [力扣原题](https://leetcode.cn/problems/majority-element/)

## 题意

给定一个大小为 `n`* *的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

## 约束

- `n == nums.length`
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
- 输入保证数组中一定有一个多数元素。

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
3
3 2 3
```

输出：

```text
3
```

## 样例 2

输入：

```text
7
2 2 1 1 1 2 2
```

输出：

```text
2
```

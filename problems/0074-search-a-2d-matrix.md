# 74. 搜索二维矩阵

中等 · 二分查找 · [力扣原题](https://leetcode.cn/problems/search-a-2d-matrix/)

## 题意

给你一个满足下述两条属性的 `m x n` 整数矩阵：

 - 每行中的整数从左到右按非严格递增顺序排列。

 - 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。

你必须编写一个时间复杂度为 `O(log(m * n))` 的解决方案。

## 约束

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j], target <= 10^4`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `matrix`：先读 rows cols，再读 rows 行、每行 cols 个整数。
- `target`：一个整数。

## ACM 输出格式

- true 或 false。

## 样例 1

输入：

```text
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
```

输出：

```text
true
```

## 样例 2

输入：

```text
3 4
1 3 5 7
10 11 16 20
23 30 34 60
13
```

输出：

```text
false
```

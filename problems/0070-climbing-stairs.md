# 70. 爬楼梯

简单 · 动态规划 · [力扣原题](https://leetcode.cn/problems/climbing-stairs/)

## 题意

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

## 约束

- `1 <= n <= 45`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `n`：一个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
2
```

输出：

```text
2
```

## 样例 2

输入：

```text
3
```

输出：

```text
3
```

# 15. 三数之和

中等 · 双指针 · [力扣原题](https://leetcode.cn/problems/3sum/)

## 题意

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

## 约束

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 第一行输出组数；随后每组输出“元素个数 + 元素”，空格分隔。

## 样例 1

输入：

```text
6
-1 0 1 2 -1 -4
```

输出：

```text
2
3 -1 -1 2
3 -1 0 1
```

## 样例 2

输入：

```text
3
0 1 1
```

输出：

```text
0
```

## 样例 3

输入：

```text
3
0 0 0
```

输出：

```text
1
3 0 0 0
```

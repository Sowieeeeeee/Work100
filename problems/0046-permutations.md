# 46. 全排列

中等 · 回溯 · [力扣原题](https://leetcode.cn/problems/permutations/)

## 题意

给定一个不含重复数字的数组 `nums` ，返回其 *所有可能的全排列* 。你可以 **按任意顺序** 返回答案。

## 约束

- `1 <= nums.length <= 6`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有整数 **互不相同**

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 第一行输出组数；随后每组输出“元素个数 + 元素”，空格分隔。

## 样例 1

输入：

```text
3
1 2 3
```

输出：

```text
6
3 1 2 3
3 1 3 2
3 2 1 3
3 2 3 1
3 3 1 2
3 3 2 1
```

## 样例 2

输入：

```text
2
0 1
```

输出：

```text
2
2 0 1
2 1 0
```

## 样例 3

输入：

```text
1
1
```

输出：

```text
1
1 1
```

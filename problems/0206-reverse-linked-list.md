# 206. 反转链表

简单 · 链表 · [力扣原题](https://leetcode.cn/problems/reverse-linked-list/)

## 题意

给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

## 约束

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `head`：先读结点数 n，再读 n 个整数。

## ACM 输出格式

- 一行，空格分隔的链表值；空链表输出空行。

## 样例 1

输入：

```text
5
1 2 3 4 5
```

输出：

```text
5 4 3 2 1
```

## 样例 2

输入：

```text
2
1 2
```

输出：

```text
2 1
```

## 样例 3

输入：

```text
0
```

输出：

```text

```

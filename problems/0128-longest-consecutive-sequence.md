# 128. 最长连续序列

中等 · 哈希 · [力扣原题](https://leetcode.cn/problems/longest-consecutive-sequence/)

## 题意

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)`* *的算法解决此问题。

## 约束

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
6
100 4 200 1 3 2
```

输出：

```text
4
```

## 样例 2

输入：

```text
10
0 3 7 2 5 8 4 6 0 1
```

输出：

```text
9
```

## 样例 3

输入：

```text
4
1 0 1 2
```

输出：

```text
3
```

# 279. 完全平方数

中等 · 动态规划 · [力扣原题](https://leetcode.cn/problems/perfect-squares/)

## 题意

给你一个整数 `n` ，返回 *和为 `n` 的完全平方数的最少数量* 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

## 约束

- `1 <= n <= 10^4`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `n`：一个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
12
```

输出：

```text
3
```

## 样例 2

输入：

```text
13
```

输出：

```text
2
```

# 131. 分割回文串

中等 · 回溯 · [力扣原题](https://leetcode.cn/problems/palindrome-partitioning/)

## 题意

给你一个字符串 `s`，请你将* *`s`* *分割成一些 子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

## 约束

- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `s`：一行字符串。

## ACM 输出格式

- 第一行输出组数；随后每组输出“字符串个数 + 字符串”，空格分隔。

## 样例 1

输入：

```text
aab
```

输出：

```text
2
3 a a b
2 aa b
```

## 样例 2

输入：

```text
a
```

输出：

```text
1
1 a
```

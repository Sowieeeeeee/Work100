# 35. 搜索插入位置

简单 · 二分查找 · [力扣原题](https://leetcode.cn/problems/search-insert-position/)

## 题意

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。

## 约束

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 为 **无重复元素 **的 **升序 **排列数组
- `-10^4 <= target <= 10^4`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。
- `target`：一个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
4
1 3 5 6
5
```

输出：

```text
2
```

## 样例 2

输入：

```text
4
1 3 5 6
2
```

输出：

```text
1
```

## 样例 3

输入：

```text
4
1 3 5 6
7
```

输出：

```text
4
```

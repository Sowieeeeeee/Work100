# 560. 和为 K 的子数组

中等 · 子串 · [力扣原题](https://leetcode.cn/problems/subarray-sum-equals-k/)

## 题意

给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 *该数组中和为 `k`** **的子数组的个数 *。

子数组是数组中元素的连续非空序列。

## 约束

- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。
- `k`：一个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
3
1 1 1
2
```

输出：

```text
2
```

## 样例 2

输入：

```text
3
1 2 3
3
```

输出：

```text
2
```

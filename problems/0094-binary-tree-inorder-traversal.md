# 94. 二叉树的中序遍历

简单 · 二叉树 · [力扣原题](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

## 题意

给定一个二叉树的根节点 `root` ，返回 *它的 **中序** 遍历* 。

## 约束

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。

## ACM 输出格式

- 一行，空格分隔的整数；空数组输出空行。

## 样例 1

输入：

```text
4
1 null 2 3
```

输出：

```text
1 3 2
```

## 样例 2

输入：

```text
12
1 2 3 4 5 null 8 null null 6 7 9
```

输出：

```text
4 2 6 5 7 1 3 9 8
```

## 样例 3

输入：

```text
0
```

输出：

```text

```

## 样例 4

输入：

```text
1
1
```

输出：

```text
1
```

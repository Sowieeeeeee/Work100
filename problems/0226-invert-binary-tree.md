# 226. 翻转二叉树

简单 · 二叉树 · [力扣原题](https://leetcode.cn/problems/invert-binary-tree/)

## 题意

给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

## 约束

- 树中节点数目范围在 `[0, 100]` 内
- `-100 <= Node.val <= 100`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。

## ACM 输出格式

- 先输出层序长度，再输出层序 token；null 表示空结点。

## 样例 1

输入：

```text
7
4 2 7 1 3 6 9
```

输出：

```text
7
4 7 2 9 6 3 1
```

## 样例 2

输入：

```text
3
2 1 3
```

输出：

```text
3
2 3 1
```

## 样例 3

输入：

```text
0
```

输出：

```text
0
```

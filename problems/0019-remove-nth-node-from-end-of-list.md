# 19. 删除链表的倒数第 N 个结点

中等 · 链表 · [力扣原题](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

## 题意

给你一个链表，删除链表的倒数第 `n`* *个结点，并且返回链表的头结点。

## 约束

- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `head`：先读结点数 n，再读 n 个整数。
- `n`：一个整数。

## ACM 输出格式

- 一行，空格分隔的链表值；空链表输出空行。

## 样例 1

输入：

```text
5
1 2 3 4 5
2
```

输出：

```text
1 2 3 5
```

## 样例 2

输入：

```text
1
1
1
```

输出：

```text

```

## 样例 3

输入：

```text
2
1 2
1
```

输出：

```text
1
```

# 763. 划分字母区间

中等 · 贪心算法 · [力扣原题](https://leetcode.cn/problems/partition-labels/)

## 题意

给你一个字符串 `s` 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 `"ababcc"` 能够被分为 `["abab", "cc"]`，但类似 `["aba", "bcc"]` 或 `["ab", "ab", "cc"]` 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 `s` 。

返回一个表示每个字符串片段的长度的列表。

## 约束

- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `s`：一行字符串。

## ACM 输出格式

- 一行，空格分隔的整数；空数组输出空行。

## 样例 1

输入：

```text
ababcbacadefegdehijhklij
```

输出：

```text
9 7 8
```

## 样例 2

输入：

```text
eccbbbbdec
```

输出：

```text
10
```

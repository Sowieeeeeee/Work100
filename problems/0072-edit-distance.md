# 72. 编辑距离

中等 · 多维动态规划 · [力扣原题](https://leetcode.cn/problems/edit-distance/)

## 题意

给你两个单词 `word1` 和 `word2`， *请返回将 `word1` 转换成 `word2` 所使用的最少操作数* 。

你可以对一个单词进行如下三种操作：

 - 插入一个字符

 - 删除一个字符

 - 替换一个字符

## 约束

- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `word1`：一行字符串。
- `word2`：一行字符串。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
horse
ros
```

输出：

```text
3
```

## 样例 2

输入：

```text
intention
execution
```

输出：

```text
5
```

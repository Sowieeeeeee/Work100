# 64. 最小路径和

中等 · 多维动态规划 · [力扣原题](https://leetcode.cn/problems/minimum-path-sum/)

## 题意

给定一个包含非负整数的 `*m* x *n*` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：**每次只能向下或者向右移动一步。

## 约束

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `grid`：先读 rows cols，再读 rows 行、每行 cols 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
3 3
1 3 1
1 5 1
4 2 1
```

输出：

```text
7
```

## 样例 2

输入：

```text
2 3
1 2 3
4 5 6
```

输出：

```text
12
```

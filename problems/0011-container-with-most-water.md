# 11. 盛最多水的容器

中等 · 双指针 · [力扣原题](https://leetcode.cn/problems/container-with-most-water/)

## 题意

给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：**你不能倾斜容器。

## 约束

- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `height`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
9
1 8 6 2 5 4 8 3 7
```

输出：

```text
49
```

## 样例 2

输入：

```text
2
1 1
```

输出：

```text
1
```

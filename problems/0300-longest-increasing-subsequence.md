# 300. 最长递增子序列

中等 · 动态规划 · [力扣原题](https://leetcode.cn/problems/longest-increasing-subsequence/)

## 题意

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列 **是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

## 约束

- 你能将算法的时间复杂度降低到 `O(n log(n))` 吗?

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
8
10 9 2 5 3 7 101 18
```

输出：

```text
4
```

## 样例 2

输入：

```text
6
0 1 0 3 2 3
```

输出：

```text
4
```

## 样例 3

输入：

```text
7
7 7 7 7 7 7 7
```

输出：

```text
1
```

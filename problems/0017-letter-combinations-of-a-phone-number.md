# 17. 电话号码的字母组合

中等 · 回溯 · [力扣原题](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

## 题意

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

## 约束

- `1 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字。

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `digits`：一行字符串。

## ACM 输出格式

- 第一行输出个数，随后每行一个字符串。

## 样例 1

输入：

```text
23
```

输出：

```text
9
ad
ae
af
bd
be
bf
cd
ce
cf
```

## 样例 2

输入：

```text
2
```

输出：

```text
3
a
b
c
```

# 152. 乘积最大子数组

中等 · 动态规划 · [力扣原题](https://leetcode.cn/problems/maximum-product-subarray/)

## 题意

给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

**请注意**，一个只包含一个元素的数组的乘积是这个元素的值。

## 约束

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何子数组的乘积都 **保证** 是一个 **32-位** 整数

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `nums`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
4
2 3 -2 4
```

输出：

```text
6
```

## 样例 2

输入：

```text
3
-2 0 -1
```

输出：

```text
0
```

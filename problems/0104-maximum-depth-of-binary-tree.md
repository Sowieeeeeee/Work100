# 104. 二叉树的最大深度

简单 · 二叉树 · [力扣原题](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

## 题意

给定一个二叉树 `root` ，返回其最大深度。

二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

## 约束

- 树中节点的数量在 `[0, 10^4]` 区间内。
- `-100 <= Node.val <= 100`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `root`：先读层序长度 n，再读 n 个 token；null 表示空结点。

## ACM 输出格式

- 一个整数。

## 样例 1

输入：

```text
7
3 9 20 null null 15 7
```

输出：

```text
3
```

## 样例 2

输入：

```text
3
1 null 2
```

输出：

```text
2
```

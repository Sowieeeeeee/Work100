# 49. 字母异位词分组

中等 · 哈希 · [力扣原题](https://leetcode.cn/problems/group-anagrams/)

## 题意

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

## 约束

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `strs`：先读个数 n，再逐行读 n 个字符串。

## ACM 输出格式

- 第一行输出组数；随后每组输出“字符串个数 + 字符串”，空格分隔。

## 样例 1

输入：

```text
6
eat
tea
tan
ate
nat
bat
```

输出：

```text
3
1 bat
2 nat tan
3 ate eat tea
```

## 样例 2

输入：

```text
1
```

输出：

```text
1
1
```

## 样例 3

输入：

```text
1
a
```

输出：

```text
1
1 a
```

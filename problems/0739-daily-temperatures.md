# 739. 每日温度

中等 · 栈 · [力扣原题](https://leetcode.cn/problems/daily-temperatures/)

## 题意

给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

## 约束

- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `temperatures`：先读长度 n，再读 n 个整数。

## ACM 输出格式

- 一行，空格分隔的整数；空数组输出空行。

## 样例 1

输入：

```text
8
73 74 75 71 69 72 76 73
```

输出：

```text
1 1 4 2 1 1 0 0
```

## 样例 2

输入：

```text
4
30 40 50 60
```

输出：

```text
1 1 1 0
```

## 样例 3

输入：

```text
3
30 60 90
```

输出：

```text
1 1 0
```

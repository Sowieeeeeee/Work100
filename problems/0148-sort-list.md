# 148. 排序链表

中等 · 链表 · [力扣原题](https://leetcode.cn/problems/sort-list/)

## 题意

给你链表的头结点 `head` ，请将其按 **升序** 排列并返回 **排序后的链表** 。

## 约束

- 链表中节点的数目在范围 `[0, 5 * 10^4]` 内
- `-10^5 <= Node.val <= 10^5`

## ACM 输入格式

- 所有数字/字符串按空白或按行读入，具体如下：
- `head`：先读结点数 n，再读 n 个整数。

## ACM 输出格式

- 一行，空格分隔的链表值；空链表输出空行。

## 样例 1

输入：

```text
4
4 2 1 3
```

输出：

```text
1 2 3 4
```

## 样例 2

输入：

```text
5
-1 5 3 4 0
```

输出：

```text
-1 0 3 4 5
```

## 样例 3

输入：

```text
0
```

输出：

```text

```
